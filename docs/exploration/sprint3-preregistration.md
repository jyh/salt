## TRACK A — the spine: the log-Chowla ascent (the entropy route)

Target (published, Tao 2016): the logarithmically-averaged two-point
Chowla conjecture — `Σ_{n≤x} λ(n)λ(n+1)/n = o(log x)` — the nearest
actual theorem to the twin frontier, and the one place a
parity-adjacent correlation has ever been broken. The B4 cost map
(sprint 2): floor ≥ 22M tokens; blocked on discrete Shannon entropy
(ABSENT from mathlib), the entropy decrement argument, the Elliott
reduction, and a Matomäki–Radziwiłł-type input. That floor ≈ the
available quota: the definition of the boundary.

**The rung ladder (each rung a registered outcome class):**
- **A-R1 — the entropy library**: discrete Shannon entropy,
  conditional entropy, mutual information, chain rule,
  subadditivity, data processing — mathlib-shaped, reusable beyond
  this project. A durable deliverable even if the sprint dies here.
- **A-R2 — the entropy decrement lemma** kernel-checked: the first
  formalization of an information-theoretic method in analytic
  number theory.
- **A-R3 — the Elliott-style reduction** + the EXACT MR fragment
  named by the recon (formalized or interfaced as a named input,
  per the recon's verdict on its cost).
- **A-R4 — the theorem** (or the honest node map of where it died —
  the depth-limit measurement one level beyond Rb-4's).

*Resolved =* any prefix of rungs landed, PLUS the cost curve
(tokens/rung vs the reuse-rich sprints' baselines). *There is no
failure class: rung 1 alone is a contribution.*

### Standing rules (THE MECHANICS, kept live; the full text is in the archive at line :7488)
- **PRE-AUTH**: pull at your seam without asking; one line at start, one at landing. A landed result is REGISTERED where
  readers look (`docs/RESULTS.md`, `docs/CAMPAIGNS.md`) in the landing act or the next pull — a result in a PR body alone is
  not of record. One write-pen per seat; read/refute/probe work floats free.
- **Statement changes are design-tier acts**, never an executor's (iron rule 1). **Build law**: `../saltbuild.sh`, never bare
  `lake`/`lean`, never piped; judge on the printed `saltbuild EXIT=N` line. **Audit law**: ≤ `[propext, Classical.choice,
  Quot.sound]` on every public landing, the receipt a PAIR from one log.
- **The limit rides beside every verdict**; a conditional result names its hypothesis in its own row. Dead ends go to
  `docs/blueprints/flags.md` (O43). **SEARCH LAW** (archive line :7488): bare name first, `grep -i`, never `| head` or
  `2>/dev/null` on an absence, print the population, census a SHA, never reuse a peer's search string, record control values.
- A row that BLOCKS carries a release condition, an owner and a re-measure date (the block register, fleet law). A row that
  tells you to HOLD is the one to re-measure first: a stale GO is caught by the next build, a stale STOP by nobody.
